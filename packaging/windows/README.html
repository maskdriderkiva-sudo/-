GBForge — ゲームボーイ用ゲームエンジン

GBDK-2020・日本語フォント・ロムライタ・エミュレータがすべて入っています。追加のインストールは不要です。

はじめかた

  1. スタートメニューかデスクトップの GBForge を起動 → ブラウザでエディタが開きます (黒い窓はログです。閉じると終了します)。
  2. 「新しいプロジェクト」で種類を選んで作成。
    • ゲームエンジン: シーン・アクター・会話をエディタで作る (Unity 風)
    • C プログラム: GBDK で自由に書く。初代 / カラー対応 / カラー専用を選べます
  3. ▶ 実行 でビルドしてエミュレータで遊べます。
  4. </> IDE で開く で Visual Studio / VS Code が開きます (GBDK と日本語フォントのインクルード設定済み)。
  5. ロムライタを USB に挿して ⤓ カートに書き込み。

日本語を表示する (C プログラム)

#include "gbjp.h"
jp_init(128, 128);
jp_print(1, 1, "ゲームボーイで日本語！");
jp_print_box(1, 3, 18, 6, "長い文章は自動で折り返します。");

コマンドライン

スタートメニューの「GBForge コマンドプロンプト」から:

GBForge doctorGBDK / ロムライタ / エミュレータの状態
GBForge new MyGameプロジェクト作成 (--type c --target both で C プログラム)
GBForge build MyGameROM をビルド
GBForge flash MyGame --port COM3カートリッジに書き込み
GBForge ide MyGameVisual Studio / VS Code で開く
GBForge jpfont --out lib/gbjp --scan src他の GBDK プロジェクト用に日本語フォントを生成

ロムライタ

CUBIC STYLE / GB Cart Flasher (FTDI) に対応。初めて接続するときに FTDI の VCP ドライバが必要な場合があります (Windows Update で自動的に入ることが多いです)。 ボーレートは基板のジャンパに合わせて設定で選びます (既定 187500)。
